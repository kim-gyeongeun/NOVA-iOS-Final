# NOVA 7.0 테스트 체크리스트

1. 예전 앱을 삭제하지 않고 같은 Bundle Identifier로 실행합니다. 기존 기록은 중요한 경우 먼저 내보냅니다.
2. AI Lab → DOCUMENT STUDIO 진입 및 버튼 확인.
3. 앨범에서 글자가 있는 사진을 선택하면 페이지 1 OCR 글자가 표시되는지 확인.
4. 텍스트 PDF로 테스트 후, 스캔된 PDF(이미지 PDF)로 OCR 동작을 테스트.
5. 시뮬레이터에서는 카메라 버튼이 비활성화되어야 합니다. 실제 아이폰에서는 카메라 권한을 허용하고 촬영 테스트.
6. 네 가지 분석 모드를 각각 실행합니다. 데모 모드에서는 `[DEMO]` 결과이며 실제 요약/검증 결과가 아닙니다.
7. 설정에서 데모 OFF, 로컬 서버 켜고 실제 AI API 키 등록 후 AI 연결 센터에서 실제 응답 확인.
8. LIVE에서 문서 분석을 수행하고, 보관함에서 결과 및 OCR 원문이 유지되는지 확인.
9. AI Hub 개별 채팅에서 스캔 PDF 첨부 후 AI 질문 테스트.
10. 앱 재실행 시 기존 채팅/팀/아레나/문서 기록 유지 여부 확인.
11. 문서 원문에 비밀 정보가 포함되면 실제 API 분석 버튼을 누르지 않습니다.

주의: OCR 오인식 가능성, AI가 제시한 출처 번호 부정확 가능성, PDF 최대 8페이지/전송 24,000자 제한.
