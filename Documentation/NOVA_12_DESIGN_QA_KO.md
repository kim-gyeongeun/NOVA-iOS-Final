# NOVA 12 — Studio White / 최종 UI QA

## 디자인 결정

- 전체 화면: 따뜻한 오프화이트(#F9FAFC에 가까운 시스템 색) + 순백 카드, 잔잔한 경계선.
- 대표 동작: 네이비 단색 Hero + 흰색 CTA, 나머지 화면은 청색을 링크/액션에만 사용.
- 하단 탭 4개: 홈 · 채팅 · AI 협업 · 보관함. 나머지는 홈의 **모든 AI 도구 보기**.
- 홈 순서: 새로운 대화 → 자주 쓰는 기능 → 최근 대화 → 모델 빠른 선택 → 모든 도구.
- 채팅: 사용자 메시지 네이비, 모델 메시지 흰 카드; 첨부·전송 작업 유지.
- 팀 스튜디오: 새 팀 만들기 + 추천 템플릿 + 저장된 팀을 분리한 작업 공간.
- 화면의 버튼과 리스트를 텍스트 중심으로 단순화하고 꾸밈용 그라데이션 없음.

## 최종 확인 절차 — 실제 Xcode에서 수행

1. iPhone 14/15와 작은 시뮬레이터에서 홈의 2열 카드가 잘리지 않는지 점검.
2. 설정에서 데모/실사용 모드 변경 후 색과 모드 상태가 맞는지 확인.
3. 홈에서 GPT, Claude, Gemini 각각 선택 → 선택 모델의 새 채팅이 열리는지 확인.
4. 새 대화, 답변 복사·공유, PDF/사진/음성 첨부 및 삭제, 키보드 입력/스크롤 확인.
5. 비교, 토론, 블라인드 평가, 팀 협업, 문서 분석, 보고서 작성, 보관함의 접근 경로 점검.
6. 팀 생성·수정·복제·실행, 과거 결과 열기, 앱 종료 후 기록 보존 확인.
7. Dynamic Type 크게 설정한 상태에서 버튼·카드·텍스트가 잘리지 않는지 확인.
8. API 사용 전에 모의 응답과 실시간 답변이 혼동되지 않도록 모드 표시 확인.
9. API 키는 Backend/.env에만 입력; 코드·ZIP·채팅에 붙여넣지 않기.
10. 실제 모델을 연결하면 GPT/Claude/Gemini 단독 채팅 → 비교 → 토론 → 협업까지 실제 응답 시연.

## 제한 및 검증

- 리디자인은 **화면 코드/공용 색상·컴포넌트만 변경**. 기존 Core/Backend/Info.plist/저장 형식/Bundle ID와 프로젝트 설정을 유지.
- 실제 macOS Xcode 빌드 및 시뮬레이터 사용성은 사용자 Mac에서 최종 확인 필요.
- API 키는 포함되지 않으며 네트워크/모델 구독/결제 환경에 따라 LIVE 호출 실패 가능.
