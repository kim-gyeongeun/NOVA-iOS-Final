# NOVA 3.0 실제 테스트 체크리스트

## 새 기능

1. **팀 스튜디오 → 팀 선택 → MISSION CONTROL** 에서 미션 예시, 목표 입력, QA 검토, 모델 대체 스위치를 확인합니다.
2. 데모 모드를 켠 상태에서 팀을 실행하면 화면이 단계별로 진행되고, 완료된 매니저·에이전트·QA·통합 단계가 **AGENT TIMELINE**에 표시됩니다.
3. 각 타임라인 행을 눌러 개별 결과를 펼치거나 공유할 수 있습니다.
4. 완료 후 **보관함 → AI 팀 결과**에서 실행 기록, 모델 이름, 실행 시간, QA 결과 및 최종 보고서를 다시 볼 수 있습니다.
5. 실행 중 **실행 중단**을 누르면 남은 단계가 중지되며, 중간 결과는 기록에 저장되지 않습니다. 이전에 완료된 API 요청은 과금될 수 있습니다.
6. 앱 설정에서 **데모 모드 OFF**, 서버 주소 입력, **서버 연결 확인**, **AI 실제 연결 테스트** 순서로 확인합니다.
7. 여러 AI 모델 키가 없다면 **연결된 모델로 자동 대체**를 켜서 일부 에이전트를 연결된 모델로 실행할 수 있습니다. 이 상태는 순수한 멀티 모델 비교와 다르며 결과에 표시됩니다.

## Xcode 업데이트 절차

- NOVA 2.0을 실행했던 앱의 Bundle Identifier를 유지한 채 새 `NOVA.xcodeproj`를 실행하세요.
- `NOVA` 앱을 삭제하지 않으면 기존 앱의 로컬 파일 저장 기록을 보통 계속 사용할 수 있습니다. 삭제하면 데이터가 사라질 수 있습니다.
- 모든 모델의 API 키는 `Backend/.env` 파일에 직접 등록해야 합니다. 이 ZIP 파일에는 어떤 사용자 키도 포함하지 않았습니다.
- Xcode에서 오류가 발생하면 첫 번째 **빨간색 빌드 오류**와 Xcode 버전을 확인하세요.

## 실제 AI 연결

```bash
cd NOVA_Project/Backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# .env에 발급받은 OPENAI_API_KEY / ANTHROPIC_API_KEY / GEMINI_API_KEY 기입
./run.sh
```

- Simulator 앱 설정 서버 주소: `http://127.0.0.1:8765`
- 실제 iPhone: 같은 Wi-Fi에서 `NOVA_HOST=0.0.0.0 ./run.sh`, 서버 주소는 `http://Mac의사설IP:8765`
- `.env` 입력만으로 AI 호출 성공을 보장하지는 않습니다. 모델 ID, 계정 권한, API 요금 및 연결 상태를 확인해야 합니다.
- Python 서버는 공개 인터넷 배포용이 아닙니다. 공개 배포하려면 HTTPS/인증/요금 한도/요청 제한 등이 필요합니다.

## 실행 수준

- **데모 모드**: 화면·타임라인·역할 흐름을 볼 수 있지만 답변은 미리 지정된 예시입니다.
- **LIVE 모드**: 실제 제공자 API 요청으로 AI가 답변합니다. 사용자의 API 키와 인터넷 연결이 필요합니다.
- **검증**: Linux Swift 코어 타입 검사 및 데모 협업 실행 테스트 완료; macOS Xcode 실제 빌드는 이 환경에서 검증할 수 없습니다.
- **단계 표시**: 완성된 API 응답이 단계별로 화면에 도착합니다. 토큰 단위 스트리밍은 아직 지원하지 않습니다.
