# NOVA 11 UI/UX 검수 체크리스트

## 홈 / 탐색
- [ ] iPhone SE/미니 계열 좁은 화면에서 4칸 탭 라벨과 퀵 액션이 잘리지 않는가
- [ ] Dynamic Type 큰 글씨로 설정 시 카드/제목이 겹치지 않는가
- [ ] 홈의 GPT·Claude·Gemini 버튼을 각각 누르면 해당 모델의 **새 대화**가 열리는가
- [ ] 홈의 **AI 팀 협업**은 협업 탭으로, **모든 도구 보기**는 기존 AI 랩으로 이동하는가
- [ ] 홈 최근 대화를 눌러 해당 기록으로 돌아갈 수 있는가
- [ ] 홈 설정 아이콘의 탭 영역이 충분하고 메뉴가 정상 열리는가

## 채팅
- [ ] 모델 선택 후 메시지 보내기/기록 유지/스크롤 자동 이동이 되는가
- [ ] 복사 버튼이 내용 전체를 클립보드에 저장하는가
- [ ] 공유 버튼으로 결과 텍스트를 내보낼 수 있는가
- [ ] 제목·볼드·목록·코드 등 Markdown 문자열이 읽기 쉽게 표시되는가 (복잡한 fenced code는 추가 검증)
- [ ] 사진 첨부와 해제, PDF 문서 추출, 음성 입력 시트가 작동하는가
- [ ] 키보드가 올라와도 텍스트 필드와 전송 버튼을 사용할 수 있는가
- [ ] 이전 대화를 길게 누른 뒤 삭제 → 확인 대화상자가 뜨는가
- [ ] 데모 모드가 실제 모델 답변처럼 오인되지 않도록 표시되는가

## 협업 / 기록 / 도구
- [ ] 기존 팀이 남아 있고, 팀 생성·수정·복제·실행이 가능한가
- [ ] 모델 비교·토론·블라인드 평가·문서 분석·스마트 라우터·보고서 도구가 모두 열리는가
- [ ] 보관함에서 기존 채팅 외 비교·협업·보고서 기록이 유지되는가
- [ ] 보고서/AI 결과 복사·공유가 작동하는가

## LIVE 연결 (키 등록 후)
- [ ] 서버가 꺼져 있을 때 연결되지 않음을 안내하는가
- [ ] 키 등록 상태와 실제 응답 테스트가 구별되어 있는가
- [ ] 실제 API 응답은 연결 센터에서 테스트했는가
- [ ] API 키나 비밀 값을 앱 소스·GitHub·공유 파일에 넣지 않았는가

## 발표 전 최종 확인
- [ ] iOS 16 및 개인 Mac Xcode 15.2의 실제 빌드 테스트
- [ ] VoiceOver 및 고대비/큰 글씨에서 주요 사용 흐름 테스트
- [ ] 네트워크가 끊긴 경우와 오류 발생 시 안내문 확인
- [ ] 강의실 발표 환경에서 서버·API·와이파이 동작 사전 리허설
