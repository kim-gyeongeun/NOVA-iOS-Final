# NOVA 9.0 검증 가이드

## 이번 버전의 변경 사항

- UI 공통 컴포넌트의 색상, 표면, 버튼, 간격과 타이포그래피를 정돈했습니다. 과한 블루/퍼플 그라데이션과 대형 장식을 제거했습니다.
- 홈을 다시 구성했습니다: 상태 표시, 빠른 실행, AI 모델, 최근 작업. 새 기능은 실제 기존 화면으로 연결됩니다.
- AI 도구 화면을 설명 중심의 간결한 목록으로 정리했습니다.
- 기존 NOVA 8.0의 대화/팀 협업/Blind Arena/문서 인식/Result Workshop/보관함 코드는 유지했습니다.
- OpenAI/Anthropic/Gemini의 API 어댑터에 대한 별도 모의 계약 테스트를 추가했습니다.

## Xcode 점검 순서

1. NOVA/NOVA.xcodeproj를 열고 iPhone 시뮬레이터로 빌드합니다.
2. 홈에서 **대화 시작**, **AI 팀 만들기** 버튼을 탭해 각각 AI 허브와 팀 스튜디오로 이동하는지 확인합니다.
3. **AI 답변 비교**, **문서 분석**, **보고서 작업실**, **블라인드 평가** 네 카드가 각각 제 화면으로 이동하는지 확인합니다.
4. AI 도구 탭에서 모든 8개 도구 화면이 열리는지 확인합니다.
5. 기존에 저장했던 대화 및 보고서가 보관함에 남아 있는지 확인합니다.
6. 설정에서 데모 모드가 ON이면 홈에 **데모 모드 · 예시 응답**으로 표시되는지 확인합니다.
7. 설정 → AI 연결 센터에서 서버 주소를 확인합니다. **키 설정됨 != 실제 연결 성공**입니다.

## LIVE API 설정 (시뮬레이터 기준)

1. 백엔드 폴더의 `start_macos.command` 실행 → 최초 실행 시 `.env`가 생성됩니다.
2. `Backend/.env` 파일을 Mac에서 열어 **자신의** API 키를 필요한 제공자에만 등록합니다. 키를 메신저·스크린샷·Git에 게시하지 마세요.
3. 다시 `start_macos.command`를 실행해 Mac의 로컬 백엔드 서버를 켭니다.
4. 앱의 설정에서 서버 주소 `http://127.0.0.1:8765` 설정 → 연결 센터에서 상태 새로고침.
5. 키가 등록된 AI에 대해 **실제 API 응답 확인**을 누르면 유료 호출이 발생할 수 있습니다. 응답이 성공한 경우에만 LIVE 연결이 검증된 것입니다.
6. 성공한 뒤 데모 모드를 OFF로 바꾸고 AI 허브에서 직접 질문을 보내 봅니다.
7. 실제 iPhone에서는 Mac과 같은 Wi-Fi에 있어야 하며, 서버를 LAN에 노출할 경우 다른 기기 접근 위험이 있습니다. 공용 Wi-Fi/인터넷에는 공개하지 마세요.

## 이 환경에서 수행 가능한 검증

- Linux Swift 파서의 구문 검사 (iOS SDK를 이용한 SwiftUI 타입 검사와 앱 실행은 포함하지 않음)
- 기존 Python API 테스트와 추가된 API 어댑터 모의 테스트 (실제 외부 네트워크 호출하지 않음)
- Xcode 프로젝트 파일 등록 및 bundle ID 등 정적 검사

**제한:** 실제 Xcode 빌드, iOS 렌더링, 외부 API 응답, API 비용, 사용 가능 모델은 사용자 Mac/개발자 계정에서 별도 검증해야 합니다.
