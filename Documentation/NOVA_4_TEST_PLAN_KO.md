# NOVA 4.0 — Blind Arena 테스트 가이드

## 신규 기능
- AI 랩 > **BLIND ARENA**: GPT, Claude, Gemini 중 서로 다른 두 모델을 지정하고 한 질문을 동시에 보냅니다.
- **익명 답변 A/B**: 답변 위치는 실행할 때 무작위로 결정합니다. 모델명은 사용자 투표 전 표시하지 않습니다.
- **투표/공개**: A, B, 무승부 중 하나를 선택하면 모델을 공개하고 기록을 저장합니다.
- **승률 보드**: 투표 결과로 모델별 승/참여 횟수를 기록하며, 데모 기록과 실제 기록을 설정 모드에 따라 구분합니다.
- **투표 이력**: AI 랩 및 보관함에서 전체 이력 열람, 답변 펼치기, 이력 삭제.
- **오류 처리**: 두 AI 중 한 명이라도 실패하면 투표를 막고 해당 오류를 표시합니다.
- **작업 취소**: 화면을 닫거나 취소 버튼을 누르면 실행 Task를 취소합니다. 외부에서 이미 처리된 API 비용을 취소하지는 못합니다.
- **기존 기록 호환**: 기존 NOVA 1/2/3 저장 JSON의 arenaMatches가 없어도 로딩 가능합니다.

## 데모 확인
1. Xcode로 `NOVA/NOVA.xcodeproj`를 열고 ▶ 실행합니다.
2. 설정에서 **데모 모드 ON**을 유지합니다.
3. `AI 랩 > BLIND ARENA`를 선택합니다.
4. GPT/Claude 등 두 AI를 선택한 상태에서 질문을 입력하고 대결을 시작합니다.
5. 답변 A/B가 모델명 없이 표시되는지 확인합니다.
6. A/B/무승부 투표 후 모델이 공개되고 스코어보드가 갱신되는지 확인합니다.
7. `보관함 > BLIND ARENA`에서 이력이 남는지 확인합니다.

데모에서 표시되는 답변은 실제 모델 생성물이 아닙니다. 데모 승률은 **AI 성능 데이터가 아니며** 단순 UI 테스트용입니다.

## 실제 모델 연결 (차후 필수 단계)
1. `Backend/.env.example`을 `Backend/.env`로 복사합니다.
2. 공식 AI 개발자 플랫폼에서 발급받은 API 키를 `.env`에만 등록합니다.
3. `Backend/run.sh`로 서버를 실행합니다.
4. 앱 설정에서 데모 OFF, 서버 주소, '모델 응답 테스트'를 확인합니다.
5. 연결된 서로 다른 두 제공자로 아레나를 실행합니다.

주의: 서로 다른 모델 2개를 호출하므로 대결 1회당 최대 2회 API 호출이 발생합니다. API 키는 절대 Swift 코드나 공개 저장소에 넣지 마세요.
