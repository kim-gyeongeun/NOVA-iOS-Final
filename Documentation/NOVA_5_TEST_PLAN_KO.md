# NOVA 5.0 테스트 안내

## 1. 팀 편집

1. 앱 실행 → 팀 스튜디오 → 팀 카드 **길게 누르기** → `팀 구성 수정`.
2. 이름, AI 제공자, 역할 지시문을 수정하고 `편집` 버튼으로 에이전트 순서를 바꿉니다.
3. 저장한 팀을 열어 변경된 순서가 반영되는지 확인합니다.
4. 팀 카드 길게 누르기 → `팀 복제`. 복사본이 별도로 생성되고 원본은 그대로인지 확인합니다.

## 2. MISSION BLUEPRINT

1. 팀 스튜디오 → 팀 선택 → Mission Control.
2. `MISSION BLUEPRINT`에서 `서비스 기획` 선택.
3. 자동 입력된 완료 기준과 보고서 형식을 확인한 뒤 원하는 문장으로 바꿉니다.
4. `QA 교차 검토`와 `QA 의견 반영해 수정 초안 작성`을 모두 켭니다.
5. `AI 팀 실행` 후 Timeline에서 매니저 → 각 역할 → QA → Revision → 최종 통합 순서를 확인합니다.
6. `전체 미션 기록 Markdown으로 공유`를 실행해 문장과 단계별 기록을 확인합니다.

## 3. 저장 기록 및 이전 버전

- 4.0에서 저장한 대화·팀·아레나 기록이 유지되는지 확인합니다.
- 5.0 팀을 복제·수정하더라도 이전에 저장한 실행 보고서가 바뀌지 않아야 합니다.
- 데모 모드에서는 실제 모델이 아닌 예시 텍스트가 생성됩니다.

## 4. API 연결은 추후 필수

- `Backend/.env.example`를 `.env`로 복사하고 본인이 발급한 API 키를 서버에 설정해야 합니다.
- 설정 화면에서 데모 모드를 끄고 실제 AI 연결 테스트를 실행하세요.
- 키 및 서버 상태 확인과 실제 AI 추론 호출은 다릅니다.
- 과금과 요청량을 먼저 확인하고 QA 수정 라운드를 활성화하세요.

## 제한 사항

- Xcode/macOS를 제공하지 않는 이 환경에서는 실제 iOS 빌드가 불가능했습니다.
- QA 수정 과정은 LLM이 비평을 참고해 문서를 개선하는 흐름이며, 외부 사실/코드 실행을 독립 검증하는 엔진은 아닙니다.
- 현재 협업 순서는 순차적입니다. 병렬·그래프 실행, 실시간 스트리밍, 클라우드 배포는 미구현입니다.
