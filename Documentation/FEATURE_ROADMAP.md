# 다음 버전에 추가하면 좋은 기능 (아직 구현되지 않음)

- Agent Marketplace: **6개 로컬 팀 템플릿 갤러리 구현됨**. 향후 커뮤니티 공유, JSON 내보내기/가져오기
- 모델 자동 라우팅: **질문 분류와 모델 추천은 구현됨** (규칙 기반, 실제 성능/비용 최적화는 미구현)
- 실제 웹 검색·논문 검색 도구 통합: 검색 결과 링크와 근거를 포함한 보고서
- 도구 호출(Function Calling): 캘린더, 파일 변환, 코드 테스트 같은 승인 기반 실작업
- 작업 그래프 편집: 드래그로 에이전트 노드 연결 및 실행 흐름 수정
- Token Usage Dashboard: 모델별 실제 토큰/비용 표시(제공자 사용량 데이터 필요)
- PDF OCR 및 다중 첨부: 스캔 문서, 이미지 여러 장, 영상 프레임 처리
- Streaming: 부분 생성 텍스트를 실시간으로 받는 SSE/웹소켓
- iCloud 동기화 + 사용자 계정: 여러 기기 간 데이터 공유
- 생산 수준의 API 게이트웨이: 인증·HTTPS·사용량 제한·요청 취소·안전한 로깅

> 이 문서는 후속 개발 아이디어입니다. 위 기능들이 현재 앱에 이미 구현되어 있다는 의미가 아닙니다.
