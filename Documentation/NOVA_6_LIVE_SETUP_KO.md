# NOVA 6.0 실제 API 연결 확인표

## 연결 단계

- [ ] `Backend/.env` 파일을 만들고 최소 한 개 제공자의 실제 API 키를 추가
- [ ] `Backend/start_macos.command` 실행 후 서버 터미널을 열어둠
- [ ] 브라우저에서 `http://127.0.0.1:8765/health` 응답 확인
- [ ] iPhone 시뮬레이터 앱 실행 → 설정 → AI 연결 센터
- [ ] 모델 상태에서 '키 설정됨' 확인
- [ ] `실제 API 응답 확인` 버튼으로 하나씩 응답 성공 여부 점검 (과금 가능)
- [ ] 데모 모드 OFF → AI 허브의 실제 응답 확인
- [ ] 단일 모델 연결이 성공한 다음 Compare/Arena/Team Studio 시험

## 문제 해결

| 증상 | 점검 방법 |
| --- | --- |
| 연결 실패 | Mac에서 서버가 실행 중인지, 서버 주소/포트가 맞는지 확인 |
| API 키 없음 | `.env`에서 키 추가 후 백엔드 재시작 |
| 401 | 해당 제공자 API 키 오류 또는 만료 여부 확인 |
| 403 | 제공자 계정의 모델 사용 권한 확인 |
| 404 | `.env` 모델 ID가 제공자에서 지원하는 정확한 ID인지 확인 |
| 429 | 잔액/과금 설정/사용량 제한 확인 |
| 아이폰만 연결 실패 | 동일 Wi-Fi, Mac 방화벽, Mac 로컬 IP, `NOVA_HOST=0.0.0.0` 실행 여부 확인 |
| 서버 연결 됐지만 AI 실패 | '연결됨'은 서버 연결만 뜻함. AI 연결 센터의 모델별 실제 응답 테스트 필요 |

## 보안

- 절대 API 키를 앱 소스코드, GitHub, 캡처 이미지에 넣지 마세요.
- `.env`는 `.gitignore` 대상이며 ZIP에도 포함되어 있지 않습니다.
- 직접 운영하는 개인 개발용 서버는 공용 인터넷에 노출하지 마세요.
- macOS에서 실행한 API 키는 아이폰에 전달되지 않고 Mac 서버에서 외부 AI에 직접 요청합니다.
- 모델별 실제 연결 테스트에 소량의 비용이 발생할 수 있습니다.
