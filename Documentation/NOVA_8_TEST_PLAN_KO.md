# NOVA 8.0 — Result Workshop 테스트 계획

## 테스트 1: 새 보고서
1. AI Lab > RESULT WORKSHOP > 새 결과물 만들기.
2. 보고서 제목·유형 선택, 저장 기록이 있다면 1~4개 체크 후 만들기.
3. 생성된 보고서를 열어 본문 수정 > 수정 내용 저장.
4. 홈으로 갔다가 다시 보고서로 돌아와 내용이 유지되는지 확인.

## 테스트 2: 수정 이력 복원
1. 같은 보고서를 다시 편집하고 저장.
2. 보고서 관리 > 수정 이력에서 이전 버전을 선택해 복원.
3. 화면에 이전 내용이 표시되는지 확인.
4. 저장하면 현재 버전도 이력에 보관되는지 확인.

## 테스트 3: 실제 파일 내보내기 (AI 불필요)
1. 보고서 관리 > Markdown 파일 내보내기.
2. 파일 앱에 `NOVA_Report.md`로 저장 후 열기.
3. 본문, 참고 자료 목록, DEMO/출처 미확인 경고가 포함되는지 확인.
4. ShareLink로 텍스트 공유도 확인.

## 테스트 4: AI 편집 / AI 검토 (DEMO)
1. 설정에서 데모 모드 ON.
2. AI 초안 생성 후 응답에 DEMO 표시가 있는지 확인.
3. "이 내용을 편집기에 적용" 후 저장.
4. AI 검토 실행 후 검토 메모에 DEMO 문구가 들어가는지 확인.

## 테스트 5: 실제 API (API 키 필요)
1. Backend에 본인의 API 키 설정 후 서버 시작.
2. 설정 > AI 연결 센터에서 실제 AI 응답 테스트 성공 여부를 확인.
3. 데모 모드 OFF > 보고서 편집 화면에서 초안 생성 또는 검토 실행.
4. 비용 발생 및 요청 실패 시 화면의 안내 메시지 확인.

## 테스트 6: 기존 데이터 유지
NOVA 7.0과 동일 번들 ID로 덮어 설치하고, 보관함의 채팅/팀/문서/대결 기록이 유지되는지 확인. 앱을 삭제하면 로컬 데이터가 사라질 수 있으므로 설치 전 백업 권장.

## 주의
- 과거 "AI 비교"와 "토론"은 저장 스키마상 DEMO 여부가 없으므로 **실행 모드 미확인**으로 표시함.
- 이전 자료에 포함된 날짜/주장은 사실로 검증된 것이 아님.
- AI 편집 요청 때 참조 원문과 사용자 작성 내용이 API 서버로 전달됨.
- 현재 서버는 개인 개발용으로만 사용. 인터넷 공개 금지.
- Linux 환경에서 Swift 파싱/모델 테스트를 실행했지만 실제 Xcode UI 타입 검사·아이폰 시뮬레이터 구동은 여기서 검증하지 못했음.
